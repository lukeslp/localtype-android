# Security

I want to hear about a security problem in LocalType before it is public.

## Which versions get fixes

Only the newest release. I don't patch older versions, so a fix comes as a new
release.

## Reporting privately

Please don't open a public issue for a security problem. Use one of these:

- On GitHub, open this repository's Security tab and choose
  **Report a vulnerability**.
- If GitHub doesn't show that button, or you would rather not use it, write to
  me through the contact page the app links under Settings → About:
  https://lukesteuber.com/#contact

## What to include

- The version, from Settings → About, and which build it is: the `fdroid` build
  from this repository or the `full` build from my download page.
- The phone and its Android version.
- The steps that show the problem, what you expected and what happened.

## Never send typed text

Don't send anything you or anyone else typed: no typing log, no file made with
Save a copy, no passwords and no screenshot that shows private text. Show the
problem with invented text.
